## 📖 使用建议

1. **循序渐进**：按照课程顺序学习，不要跳过基础
2. **动手实践**：每个示例都要自己运行，并尝试修改参数

4. **记录笔记**：记录你的实验结果和心得

---

## ⚠️ 重要提示

1. **回测≠实盘**
   - 历史表现不代表未来
   - 回测忽略了滑点、流动性等因素

2. **风险第一**
   - 永远设置止损
   - 不要过度杠杆
   - 控制单笔交易风险

3. **避免过拟合**
   - 不要过度优化参数
   - 使用样本外测试验证
   - 保持策略简单有效

4. **持续学习**
   - 市场在不断变化
   - 定期评估策略表现
   - 保持学习的态度
